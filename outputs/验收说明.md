# 小型 ERP 交付验收

交付日期：2026-11-04。交付形式：可运行源代码与独立本地模拟数据库，未接入或改动用户现有 Supabase/Vercel 项目。

## 结果

- 43 张实际关系表；20 类单据分别不少于 10,000 张，合计 300,000 张；469,246 行明细、270,000 条单据关联。
- 10,000 条生产报工、10,000 张成本计算单、90,772 条库存事务、40,000 条核销、140,000 张凭证和 320,000 条凭证分录。
- 完整模拟数据通过 21 项一致性检查，差异均为 0；逐项数量及检查名称见 data-validation.json。
- 在按 requirements.txt 新建的 Python 3.12 虚拟环境中，11 项业务测试通过。涵盖登录与写入保护、各模块读取、价格计算与版本、状态/下游防重、库存不足回滚、法人越权与只读权限、跨法人核销拦截、生产成本完整闭环、采购净额防重复和独立费用应付。
- 浏览器实测：登录成功；销售订单列表显示 20,000 张；明细显示物流、金额、批次与下游发货单；成本列表显示 10,000 张；利润报表显示 13 个产品规格的材料出库成本与管理毛利；新增生产表单可切换法人，仓库随之更新。最终分类查询、清空条件查询及明细/汇总金额核对均通过。
- 已检查窄屏和 1440px 桌面布局；绿色操作栏、左侧模块、单据页签、四列表单和横向明细表参考用户截图。截图随源码包提供。

## 尚未验证和已知边界

未连接 Supabase、未执行 Vercel 构建或云端部署、未进行 PostgreSQL 实例端的事务和并发验证。已生成 PostgreSQL DDL，配置服务端连接、RLS 隔离和 Supabase Auth，并对照官方 FastAPI 部署文档检查入口及依赖配置。云端验收需要用户选定目标并配置连接信息后进行。

本版采用单产品、整单一次完工核算；批次余额法出库，单行不能跨多个库存批次；单价输入精确到分；未实现银行支付、税控开票、退货红冲、复杂在制品、资产折旧和集团合并抵销等正式系统功能。利润为“发出金额减出库成本”的管理毛利，不是集团净利润。详见 docs/业务与计算口径.md。

所有历史业务为关联模拟数据，只有组织名称、部分物料名称/编码和界面字段参考附件。不得将模拟数据作为企业实际经营记录或金蝶官方数据库结构使用。


新增物料分类验收：27 项物料、13 个分类节点；7 个照片品种均有模拟业务历史。21 项检查包括分类叶节点、散装无包材、BOM 领料数量及实际材料成本。旧模拟库和交付包已备份；详见 docs/物料分类升级说明.md。
