# 客户合同档案

入口：购销合同 → 客户合同档案。原有采购合同、销售合同模拟单据继续保留。新增能力是销售人员上传并提交的商业合同档案。

## 已实现

- 按所属法人选择业务组织、销售人员、适用客户（多选）。客户必须在该法人的客户范围内，不能选择本法人自身作为客户；销售人员必须属于该法人。现有客户授权模型是 `partner_role.company_id`，当前每法人一个业务组织，未引入独立销售人员客户分配表。
- 表单包含合同编号、名称、类型、签订日期、有效期、结算条件、服务框架、补充说明。
- 商品价格明细关联当前法人销售成品，显示物料与规格，记录数量区间、协议单价、税率、含税口径、备注。现有盐品单位为吨，价格为元/吨；金额入库为整数分。
- 商品价格协议、服务框架协议、综合协议三种类型；商品合同必填价格，服务合同必填服务框架。
- 草稿 → 提交 → 管理员审核通过 / 退回；提交人可撤回待审核合同，管理员可填写原因后终止已审核合同。
- 保存后上传附件；提交前至少一份。草稿或退回状态可修改表单及上传、移除附件。已提交、已审核合同冻结内容和附件，保留操作记录。
- PDF、DOC/DOCX、XLS/XLSX、JPG/PNG，每文件 3 MiB（页面简称 3 MB），每合同最多 20 份；扩展名与基础文件签名校验，DOCX/XLSX 校验容器目录结构。没有做病毒扫描和合同文本识别。
- 法人范围由现有会员权限校验。只读角色不可写；普通操作员只能修改自己录入的合同；管理员可管理该法人合同。审核只允许管理员。使用 `version` 防止并发覆盖。
- 此模块管理协议与附件，不签署合同，不自动覆盖销售订单价格、不自动生成业务单据。协议适用范围内若有多份有效合同，应由业务人员确认采用哪份。

## 数据与附件分开保存

新增 5 张业务表：`sales_contract`、`contract_customer`、`contract_price`、`contract_attachment`、`contract_event`。数据库只保存表单、附件索引、大小、摘要和操作记录；文件内容不放 PostgreSQL。

本地使用 `work/contract-files` 私有目录，经有权限的下载接口读取。该目录不属于 `/assets`，被 Git 忽略。开发用独立预览环境可覆盖 `CONTRACT_LOCAL_DIR`。

线上使用同一 Supabase 项目中的 **私有 Storage 桶 `erp-contracts`**。不需要第二个数据库、不需要 Vercel Blob。对象路径为 `法人ID/合同ID/随机ID.扩展名`。后端先校验当前账户及法人权限，再上传或生成 60 秒有效的下载链接。浏览器不能获得存储密钥。

新增表启用 RLS，撤销 `anon` / `authenticated` 的直接访问，沿用现有 FastAPI 服务端数据库访问方式。桶保持 private，不添加浏览器直接读写策略；请同时确保现有 `storage.objects` 没有覆盖所有桶的宽泛访问策略。

## 上线所需资源与配置

仅在准备上线时执行以下步骤；本次本地开发没有修改线上数据库或创建桶。

1. 在既有数据库执行一次增量脚本 `supabase/contracts.sql`。不要在已有数据库重新执行整个 `schema.sql`，不要重新播种历史数据；`ERP_INITIALIZE_DATABASE` 保持 `0`。
2. 在同一 Supabase 项目创建 `erp-contracts` 私有桶。可通过 Dashboard 创建，或在受控本地终端设置相应环境变量后运行 `python scripts/setup_contract_storage.py`。该命令只手动执行，不会随构建自动运行。
3. 在 Vercel Production 添加以下三项，然后重新部署。原来的 `DATABASE_URL`、`SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY`、`AUTH_MODE` 保留。

| 变量 | 值 | 保存位置 |
|---|---|---|
| `CONTRACT_STORAGE_BACKEND` | `supabase` | Vercel Production Config |
| `CONTRACT_STORAGE_BUCKET` | `erp-contracts` | Vercel Production Config |
| `SUPABASE_SECRET_KEY` | Supabase 项目 API Keys 中的服务端 Secret key | Vercel Production Secret，仅后端 |

不要将 Secret key 贴入聊天、提交仓库或写入前端脚本。示例模板只含占位符。已有 publishable key 不能替代该服务端密钥。

4. 上线后，用管理员 / 操作员 / 只读账户验证保存、上传、下载、提交审核及跨法人拒绝访问。本地已覆盖私有存储 HTTP 请求的模拟测试，但真实线上 Storage 尚未联调，不能视为已上线。

当前文件经 FastAPI 转发，3 MiB 限额为 Vercel 请求体留出余量。更大扫描件需拆分 / 压缩，后续可扩展浏览器直传与断点续传。容量和流量使用当前 Supabase 项目的 Storage 配额，实际费用取决于套餐和用量。

附件移除先提交数据库索引与权限变更，再删除存储对象。如果存储删除失败，接口返回 `storage_cleaned=false` 并记录待清理附件 ID；对象可能暂时占空间，但无法再经合同下载接口访问。上传入库失败会尝试清理刚上传对象。存储对象与数据库并非跨服务原子事务。

## 本地运行与验证

`start.ps1` 会检查并创建新增表，不改写既有模拟业务数据；已有运行进程需要重启后才会加载新接口。也可先运行 `python scripts/init_db.py`，再启动 FastAPI。

自动验证命令：`python -m pytest -q`。新增测试使用独立临时数据库和临时附件目录，不会改动演示库或线上数据。
