# 特殊价格申请静态表

线上项目：vyulbopmxltjnptuqmcp。表：public.pricechangerecord。批次：pricechange_sim_20261104_v1。

已写入并查询验证 1,200 行，申请日期按北京时间覆盖 2025-11-04 至 2026-11-03。7 个申请主体、12 种产品，包含食品加工用盐、小包装、精工饲料盐、散湿盐、海盐散原盐、药用盐、软水剂。工业精制盐的二级品种仍待确认，因此本批不纳入。

线上 ERP 的 company/material/document 表当前为空，本批依据本地已交付 app/catalog.py 和 app/materials.py 生成独立快照；不写入这些业务表，也不依赖其外键。公司合资股权属性未经核实，按关联营销法人模拟申请主体，保留简称与名称确认标识。区域及价格申请均为模拟；原始价格来自当前 ERP 目录价，不代表历史真实成交价。

## 字段口径

| 字段 | 含义 |
|---|---|
| application_no | 唯一申请编号 |
| group_company_code/name | 鲁盐集团主体 |
| applicant_company_code/name | 申请法人编码、名称快照 |
| applicant_legal_name_confirmed | ERP 中法人名称是否已确认 |
| applicant_relationship_note | 关联主体、合资属性核实情况 |
| sales_region/province/city | 销售区域、省份、城市 |
| category_level1/category_level2 | ERP 两级分类 |
| material_code/material_name | 物料编码和名称 |
| model/specification | ERP 产品特征与规格；不虚构技术型号 |
| salt_origin/packaging/pack_weight_kg | 盐源、包装方式、外包装净重（kg）；散装净重为空 |
| weight_scale/min_quantity_ton/max_quantity_ton | 订单吨位区间，下限含、上限不含；最高档上限为空 |
| requested_quantity_ton | 本项目申请数量，吨 |
| original_price/requested_price | 原始目录价、申请价，人民币元/吨 |
| price_change_amount | 自动计算：申请价－原始价，元/吨 |
| price_change_percent | 自动计算：(申请价－原始价)/原始价×100；-5 表示降价 5% |
| approved_price | 通过后的执行价；待审、驳回、撤回时为空 |
| price_includes_tax/tax_rate/freight_included | 本批含税 13%、不含运费，与当前 ERP 模拟口径一致 |
| application_scope/project_code | 只适用于唯一专项项目；不是整个区域统一调价 |
| application_reason/review_note | 模拟申请原因、审核说明 |
| applied_at/valid_from/valid_to | 带时区时间；有效期为左闭右开，仅审批通过后有执行效力 |
| status | submitted 待审、approved 通过、rejected 驳回、withdrawn 撤回 |
| is_completed/completed_at | 审批流程是否结束、结束时间；完成不等于价格已失效 |
| is_simulated/source_basis/seed_batch/snapshot_as_of | 模拟标识、数据依据、批次、静态观察日期 |

## 验证结果

- 审批通过 819 行、驳回 234 行、撤回 117 行、待审 30 行。
- 审批完成 1,170 行，未完成 30 行。
- 原始目录价 330–2,300 元/吨；申请调价幅度 -12% 至 +4%。
- 调价公式、有效期、审批时间和吨位区间异常均为 0。
- 全部记录 is_simulated=true；RLS 已启用，anon/authenticated 无直接读写权限，沿用 ERP 后端访问模式，可在 Supabase Table Editor/SQL Editor 管理。

当前时间有效且审批通过的申请可在 SQL Editor 查询：

```sql
SELECT * FROM public.pricechangerecord
WHERE status='approved' AND valid_from<=now() AND now()<valid_to
ORDER BY applied_at DESC;
```

建表脚本：supabase/pricechangerecord.sql。数据脚本：supabase/pricechangerecord_seed.sql。生成器：scripts/build_pricechange_seed.py。插入按唯一申请号跳过已有记录，不覆盖现有数据；本表为独立补充，不加入原 ERP 的云端全量初始化流程。
